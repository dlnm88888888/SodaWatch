# 汽水领时长 · SodaWatch

之前参考的 GitHub 开源方案在我使用的汽水音乐版本上已经失效，也没有提供可直接安装的安卓 App。因此我写了 SodaWatch，打包成 APK，方便直接在安卓手机上安装使用。

在 Android 手机上识别汽水音乐的广告界面，等待广告播完，并按设定轮数处理领取奖励和继续观看。画面识别在手机本地完成。项目与汽水音乐官方无关联。

## 安装和运行

1. 从本仓库的 **Releases** 下载 APK，在 Android 11 或更高版本的手机上安装。手机还需安装汽水音乐。
2. 打开「汽水领时长」，点「打开无障碍设置」，启用同名服务。部分手机从浏览器安装 APK 后，会先要求在应用信息里允许受限设置。
3. 选好轮数，或勾选「不限轮数」，然后点「开始并打开汽水音乐」。如果还没进入广告，可手动打开汽水音乐里的领奖广告入口。任务期间会保持手机亮屏，请让汽水音乐留在前台。
4. 要结束任务，返回助手点「停止任务」，或离开汽水音乐。汽水音乐提示次数用完或长时间没有进展时，任务也会结束。

## 运行日志和权限

无障碍服务在任务运行期间用来读取汽水音乐界面、截图识别文字，并模拟点击。截图在内存中处理。助手 APK 未声明互联网访问权限。

「查看运行日志」可以将最近一次完整日志保存到下载目录，或通过系统分享面板发送。日志可能包含界面文字、控件位置和应用包名。公开提交问题前，请检查并遮盖昵称、账号等个人信息。

## 从源码构建

使用 JDK 17、Gradle 8.9 和 Android SDK Platform 35。可用 Android Studio 打开项目根目录，也可在项目根目录运行：

```sh
gradle :app:assembleDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/`。发布更新时需使用与已有安装包相同的签名证书。


## 1.0.7 验证情况

在 iQOO Neo10、汽水音乐 21.5.0 上验证了广告续播。新版增加了「惊喜福利」下载弹窗的关闭规则，已通过真机截图验证按钮定位。该弹窗在新版真机测试中未再次出现。
